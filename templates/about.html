Core

A complete, beginner-friendly web application for monitoring multiple systems in a laboratory environment. The system collects metrics (CPU, RAM, Disk, etc.) from each system and displays them on a centralized dashboard with predictive maintenance alerts.

  • Real-time Monitoring
  • Professional Dashboard
  • Predictive Maintenance
  • Health Scoring
  • Historical Tracking
  • Interactive Charts
  • QR Code Access
  • Responsive Design
